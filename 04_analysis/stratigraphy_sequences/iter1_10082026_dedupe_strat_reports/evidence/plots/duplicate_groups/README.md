# Original duplicate groups before deduplication

Open the [interactive map](duplicate_groups_map.html) or [static overview](duplicate_groups_overview.png). These show the original iteration 0 records: 71 groups, 166 well records, and 84 recorded locations. They are retained as the before-deduplication evidence for iteration 1.

Blue points identify groups with one shared recorded location; orange identifies differing locations within a group; red links identify the two different-group pairs within 100 metres. The overview has a 5 km scale and detailed close-pair panels. The interactive map has an adjustable distance scale, search, group filters, popups, and optional 100 m circles. Its background uses the [USGS topographic map](https://basemap.nationalmap.gov/arcgis/rest/services/USGSTopo/MapServer). Select **Wells only** to hide background tiles while keeping the well controls. Internet access is required to load the interactive library and background; the static overview works without it.

These files were initially copied without changing their bytes on October 9, 2026. Later that day, the interactive HTML was repaired after OpenStreetMap returned blocked background images: it now uses USGS, offers a **Wells only** option, and reports tile failures. The well data and static overview remain unchanged. The previous HTML and manifests are preserved under [audit/map_background_fix](../../../audit/map_background_fix/), and [map_manifest.json](map_manifest.json) records the updated file hashes and generation methods. Original generator files remain under `04_analysis/stratigraphy_sequences/maps/duplicate_groups/`; their paths and hashes are recorded rather than duplicating scripts that would write to the completed iteration.

For the results of deduplication, open the [before-and-after comparison](../before_after/README.md). Original map copies remain outside the iteration for existing links. No data, archives, or deduplication decisions changed when these visuals were added.
